# animetosho-provider

### AnimeTosho extension for Seanime

Search anime torrents directly inside Seanime using AnimeTosho.

</div>

---

## ✨ Features

- 🔍 Anime search
- 📺 Episode listing
- 🧲 Torrent & magnet support
- ⚡ Fast and lightweight
- 🔌 Seamless Seanime integration

---

## 📦 Installation

### 1. Open Seanime

Go to:

```txt
Settings → Extensions → Add Extension
```

---

### 2. Paste the manifest URL

```txt
https://raw.githubusercontent.com/0utLunar/animetosho-provider/main/manifest.json
```

---

### 3. Install the extension

After installing, restart Seanime if necessary.

---

## 🛠️ Requirements

- Seanime installed
- Internet connection
